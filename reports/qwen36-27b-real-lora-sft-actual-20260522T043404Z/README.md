## Boundary

This is an actual real-checkpoint Qwen3.6-27B bounded full-layer LoRA SFT run:
the hidden vector comes from downloaded BF16 safetensors after Psionic's Rust
row-sparse layer-stack smoke, base weights stay frozen, and the run exports a
loadable LM-head LoRA adapter plus checkpoint state. It is not exact
full-vocabulary generation, private Harvey evaluation, or full transformer
backprop through `q_proj`, `k_proj`, `v_proj`, `o_proj`, `gate_proj`,
`up_proj`, or `down_proj`.

The eval is a deterministic public replay smoke over three public Harvey tasks.
It records workflow and promotion-gate evidence for this adapter, not live
legal quality or performance on private Harvey tasks.
